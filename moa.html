로그인 중

로그인한 사용자가 상품을 보고 있습니다.

작업 노트

로그인 시 Django는 세션을 생성하고 DRF 토큰과 사용자 정보를 응답합니다. Vue는 토큰과 사용자 정보를 localStorage에 저장해 페이지를 다시 열어도 사용할 수 있게 했습니다.

화면을 복원하는 기준

저장된 사용자 정보가 있으면 Vue가 GET /api/accounts/me/를 호출합니다. 공통 요청 함수는 저장한 토큰을 Authorization: Token … 헤더로 보냅니다. 응답이 오면 프로필을 갱신하고, 인증 오류나 연결 실패로 조회할 수 없으면 토큰과 사용자 정보를 지워 비로그인 화면으로 돌아갑니다.

내가 구현한 화면

현재 자산과 월 저축 여력 등을 입력하는 폼, 상품 조회 화면, API 응답 표시를 맡았습니다. 팀 서비스는 조건에 맞는 세 상품을 비교하고 선택한 금리로 목표까지 걸리는 기간을 보여줍니다.

상품 목록이 비었을 때

Postman으로 상품 조회 API를 직접 불러 응답에 데이터가 있는지 확인했습니다. 같은 상품이 API 응답에는 들어 있었고 Vue의 목록에는 보이지 않았습니다. 그래서 서버의 데이터 수집부터 다시 점검하는 대신, 응답을 받은 뒤 화면에 표시하기까지의 구간으로 조사 범위를 좁혔습니다. 이때 기록으로 남은 것은 원인을 좁힌 단계까지입니다.
